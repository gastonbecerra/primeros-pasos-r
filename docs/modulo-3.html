Tercer paso. Manipulación de datasets

Objetivo

En este tutorial vamos a aprender a manipular una tabla de datos con algunos verbos básicos de dplyr. Para el final, vas a poder ordenar resultados, calcular porcentajes, seleccionar columnas, filtrar casos y crear nuevas variables.

La idea es avanzar desde una primera exploración de la base hacia operaciones que nos permitan preparar los datos para responder preguntas de investigación.

Cargamos paquetes y datos

Como siempre, empezamos cargando los paquetes que vamos a usar:

library(tidyverse)
library(janitor)

Luego cargamos nuevamente la base de datos:

encuesta_ia <- read_csv(
  "https://raw.githubusercontent.com/gastonbecerra/primeros-pasos-r/refs/heads/main/data/encuesta_ia_subset.csv",
  show_col_types = FALSE
)

Ordenar resultados

En el tutorial anterior usamos count() para contar cuántos casos hay en cada categoría.

Por ejemplo:

count(encuesta_ia, area_trabajo_grupo)
# A tibble: 3 × 2
  area_trabajo_grupo                        n
  <chr>                                 <int>
1 Consultoría / servicios profesionales    39
2 Educación                                50
3 Salud y servicios sociales               50

Muchas veces conviene ordenar los resultados de mayor a menor. Para eso agregamos arrange():

count(encuesta_ia, area_trabajo_grupo) %>%
  arrange(desc(n))
# A tibble: 3 × 2
  area_trabajo_grupo                        n
  <chr>                                 <int>
1 Educación                                50
2 Salud y servicios sociales               50
3 Consultoría / servicios profesionales    39

Acá aparece un operador nuevo: %>%.

Este operador se llama pipe y permite encadenar operaciones. Podemos leerlo como “después”. Entonces, el código anterior puede leerse así:

contá los casos por área de trabajo y después ordená el resultado de mayor a menor.

También podemos ordenar de menor a mayor:

count(encuesta_ia, area_trabajo_grupo) %>%
  arrange(n)
# A tibble: 3 × 2
  area_trabajo_grupo                        n
  <chr>                                 <int>
1 Consultoría / servicios profesionales    39
2 Educación                                50
3 Salud y servicios sociales               50

Calcular porcentajes

También podemos calcular porcentajes. Para eso, después de contar, creamos una nueva columna con mutate():

count(encuesta_ia, frecuencia_uso_ia) %>%
  mutate(porcentaje = n / sum(n) * 100)
# A tibble: 4 × 3
  frecuencia_uso_ia     n porcentaje
  <chr>             <int>      <dbl>
1 esporadicamente      25      18.0 
2 frecuente            54      38.8 
3 nunca                 6       4.32
4 ocasional            54      38.8

Con esta tabla ya no vemos solamente cuántas personas hay en cada categoría, sino también qué porcentaje representa cada una sobre el total.

Si queremos redondear el porcentaje, podemos usar round():

count(encuesta_ia, frecuencia_uso_ia) %>%
  mutate(porcentaje = round(n / sum(n) * 100, 1))
# A tibble: 4 × 3
  frecuencia_uso_ia     n porcentaje
  <chr>             <int>      <dbl>
1 esporadicamente      25       18  
2 frecuente            54       38.8
3 nunca                 6        4.3
4 ocasional            54       38.8

Primera lectura descriptiva

Con estas operaciones podemos empezar a responder algunas preguntas básicas:

  • ¿cuántas personas hay en cada grupo de edad?
  • ¿cómo se distribuyen las áreas de trabajo?
  • ¿con qué frecuencia usan IA las personas encuestadas?
  • ¿qué categorías tienen más casos?
  • ¿qué categorías tienen pocos casos y conviene interpretar con cuidado?

Este tipo de exploración no es un trámite previo al análisis. Es parte del análisis.

Antes de comparar grupos, calcular indicadores o hacer gráficos, necesitamos saber cómo está compuesta la base. Si un grupo tiene muy pocos casos, por ejemplo, sus resultados pueden ser poco estables. Si una categoría concentra la mayoría de las respuestas, eso también condiciona la interpretación.

Contar después de filtrar

Filtrar no es solo “recortar” la base. Muchas veces filtramos para responder preguntas más específicas.

Por ejemplo:

Entre quienes trabajan en educación, ¿con qué frecuencia se usa IA?

encuesta_ia %>%
  filter(area_trabajo_grupo == "Educación") %>%
  count(frecuencia_uso_ia) %>%
  mutate(porcentaje = round(n / sum(n) * 100, 1))
# A tibble: 4 × 3
  frecuencia_uso_ia     n porcentaje
  <chr>             <int>      <dbl>
1 esporadicamente       7         14
2 frecuente            22         44
3 nunca                 1          2
4 ocasional            20         40

Leído paso a paso:

  1. tomamos la base encuesta_ia;
  2. filtramos los casos del área de educación;
  3. contamos la frecuencia de uso de IA;
  4. calculamos el porcentaje.

Esta forma de escribir código nos permite transformar una pregunta en una secuencia ordenada de operaciones.

Crear nuevas variables

Para crear nuevas columnas usamos mutate().

Por ejemplo, podemos crear una variable que indique si la persona tiene 45 años o más:

encuesta_ia <- encuesta_ia %>%
  mutate(
    mayor_45 = edad >= 45
  )

Ahora podemos contar esta nueva variable:

count(encuesta_ia, mayor_45)
# A tibble: 2 × 2
  mayor_45     n
  <lgl>    <int>
1 FALSE       69
2 TRUE        70

La nueva columna mayor_45 toma valores TRUE o FALSE.

  • TRUE: la condición se cumple;
  • FALSE: la condición no se cumple.

También podemos crear una variable con categorías de texto usando case_when().

encuesta_ia <- encuesta_ia %>%
  mutate(
    intensidad_uso = case_when(
      frecuencia_uso_ia %in% c("nunca", "esporadicamente") ~ "baja",
      frecuencia_uso_ia == "ocasional" ~ "media",
      frecuencia_uso_ia == "frecuente" ~ "alta"
    )
  )

Y luego contarla:

count(encuesta_ia, intensidad_uso)
# A tibble: 3 × 2
  intensidad_uso     n
  <chr>          <int>
1 alta              54
2 baja              31
3 media             54

Esta operación muestra algo importante: muchas veces las variables que usamos en el análisis no vienen directamente en la base, sino que las construimos a partir de decisiones analíticas.

Si quisiéramos guardar esos cambios, tendríamos que hacer:

encuesta_ia_renombrada <- encuesta_ia %>%
  rename(
    area = area_trabajo_grupo,
    frecuencia = frecuencia_uso_ia
  )

Seleccionar, filtrar y ordenar

Podemos combinar varios verbos en una misma secuencia.

Por ejemplo:

encuesta_ia %>%
  filter(frecuencia_uso_ia == "frecuente") %>%
  select(edad, grupo_edad, area_trabajo_grupo, frecuencia_uso_ia) %>%
  arrange(edad)

El orden de las operaciones importa. No es lo mismo seleccionar primero, filtrar después, o crear una variable antes de hacer un conteo.

Mini-ejercicios

Probá responder estas preguntas con código:

  1. ¿Cuántas personas de cada área usan IA frecuentemente?
  2. ¿Cuál es la distribución de grupos de edad entre quienes usan IA ocasionalmente?
  3. ¿Qué porcentaje de la base tiene 45 años o más?
  4. ¿Cómo cambia la frecuencia de uso si miramos solo el área de salud y servicios sociales?

Una posible respuesta para la primera pregunta:

encuesta_ia %>%
  filter(frecuencia_uso_ia == "frecuente") %>%
  count(area_trabajo_grupo) %>%
  mutate(porcentaje = round(n / sum(n) * 100, 1)) %>%
  arrange(desc(n))
# A tibble: 3 × 3
  area_trabajo_grupo                        n porcentaje
  <chr>                                 <int>      <dbl>
1 Educación                                22       40.7
2 Consultoría / servicios profesionales    16       29.6
3 Salud y servicios sociales               16       29.6

Cierre

En este tutorial aprendimos a manipular una tabla con operaciones básicas:

Función Para qué sirve
count() contar casos por categoría
arrange() ordenar resultados
mutate() crear nuevas variables
select() seleccionar columnas
filter() filtrar filas
rename() cambiar nombres de variables

Estas funciones son herramientas básicas para empezar a construir un análisis. Pero todavía estamos trabajando con variables tomadas de manera separada.
